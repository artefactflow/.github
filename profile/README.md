ArtefactFlow is one source of truth for every software artefact, its versions and its SBOM, so you can answer what's inside a release, whether it's vulnerable, and where it's deployed, with confidence.

This organisation is home to the open-source integrations that connect ArtefactFlow to the systems you already run: CI/CD pipelines, GitOps tooling and developer portals. Each repository is standalone and talks to ArtefactFlow through its public API.

To learn more about the platform, visit [artefactflow.com](https://www.artefactflow.com) or read the [documentation](https://docs.artefactflow.com).
